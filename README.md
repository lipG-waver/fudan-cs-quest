# 🎮 Fudan CS Quest - 复旦计算机新手闯关

> 一个为复旦（说不定可以扩展到其他高校）大一新生设计的编程能力闯关游戏，通过有趣的挑战来检验和提升ai时代的计算机能力。

## 📌 这是什么？

这是一个面向**零基础到入门级**的编程挑战项目。如果你：
- 🎓 是复旦大一新生，想找志同道合的编程伙伴
- 💻 对计算机项目感兴趣，想参与实际开发
- 🚀 想加入我们的开源项目团队

那就来挑战吧！**不要害怕**，这些题目都是精心设计的，Bing（国内可访问）、Google 和文档（一切文档）是你的好朋友。

## 🚀 开始之前

### 克隆项目

你需要想方设法安装Git. 

按照本人在Windows系统上安装Git的经验，哪怕你使用Bing登上官网以后，下载Git速度十分缓慢。

因此推荐你上ghproxy.link这个网站找找有没有解决方案。

下载完Git以后，找找git clone的用法。或者让大语言模型帮你生成一行代码，将我的代码库克隆到你的本地呢～
