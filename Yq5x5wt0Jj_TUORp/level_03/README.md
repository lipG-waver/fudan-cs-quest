# 🔍 Level 3: 黑盒调试挑战 - 神秘成绩计算器

## 📋 挑战说明

这是一个**黑盒测试挑战**。你拿到了一个成绩计算器，但是：
- ❌ 你看不到核心计算逻辑（代码被混淆）
- ✅ 你可以运行它
- ✅ 你可以设计测试用例
- ✅ 你可以观察输入和输出

**你的任务**：通过黑盒测试找出系统中的5个bug！

## 🎯 为什么这个挑战不能用LLM解决？

1. **需要真实运行** - LLM不能实际执行代码
2. **需要实验设计** - 必须设计多组对比实验
3. **需要观察分析** - 要记录多次测试结果并找规律
4. **需要推理思考** - 从现象推测内部逻辑

这是真正的**程序员思维训练**！

### 第三步：设计实验

基于观察到的异常，设计更多测试用例来验证你的猜测。

**对比实验示例：**

```python

calc = MysteryGradeCalculator()

# 实验1：测试课程数量的影响

print("3门课:", calc.calculate_gpa([85, 90, 88]))
print("4门课:", calc.calculate_gpa([85, 90, 88, 92]))
print("5门课:", calc.calculate_gpa([85, 90, 88, 92, 87]))

# 实验2：测试高分的影响
print("中等分:", calc.calculate_gpa([85, 85, 85]))
print("高分:", calc.calculate_gpa([92, 93, 94]))
print("超高分:", calc.calculate_gpa([96, 97, 98]))

# 继续设计你的实验...
# 完全可以仿照这里修改你的代码。
```

## 💡 黑盒测试技巧

### 1. 边界值测试
测试临界点附近的值：
- 0分、60分（及格线）、90分、100分
- 1门课、2门课、3门课...

### 2. 等价类划分
将输入分组测试：
- 不及格（0-59）
- 及格（60-69）
- 中等（70-79）
- 良好（80-89）
- 优秀（90-100）

### 3. 对比实验
改变一个变量，观察结果：
```python
# 只改变课程数量
calc.calculate_gpa([85, 90])        # 2门
calc.calculate_gpa([85, 90, 88])    # 3门
calc.calculate_gpa([85, 90, 88, 92]) # 4门
```

### 4. 极端情况测试
- 全满分：[100, 100, 100]
- 全0分：[0, 0, 0]
- 极大差异：[0, 100, 50]

### 5. 记录和可视化
建议创建一个表格记录所有测试：

| 测试# | 输入 | 实际GPA | 预期GPA | 差异 | 备注 |
|------|------|---------|---------|------|------|
| 1    | [85,90,88] | 3.65 | 3.49 | -0.16 | 异常偏高？ |
| 2    | [95,96,97] | 3.34 | 3.87 | -0.53 | 高分反而低！|
